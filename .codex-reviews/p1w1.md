5. **Runner-contract migration** — only AtomicTransaction.java migrated. Sufficient for the plan's named highest-priority example, insufficient as a general claim about runner-contract delivery. Other examples that print failure but exit 0 still become green synthetic results.
6. **README deferral** — acceptable as a deliberate Wave-2 deviation (the milestone table puts tutorial READMEs in P1W2). Reject any closeout that presents P1W1 as delivering Phase 1's educational side.
